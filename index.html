pkprimary key. An explicit pk wins over Id.

        
nullcolumn may be NULL (default is NOT NULL)

        
uniqueUNIQUE constraint (this is how 1-1 is made)

        
-> Tableforeign key to the table's primary key (normally Id). The FK column gets its type.

        
-> Table.Colforeign key to a specific column. It should be the primary key or unique.

        
vcvarchar(128). Any other type is written as-is: int, text, date, datetime, decimal(8,2)…
